Concept Summary

Parsing: Converting HTML source code into a structured format.

Tokenization: Breaking HTML into smaller tokens such as tags and text.

DOM Tree: Tree representation of HTML elements.

CSSOM Tree: Tree representation of CSS rules.

Render Tree: Combination of DOM and CSSOM used to render the webpage.

Event Bubbling: Event travels from child to parent.

Event Capturing: Event travels from parent to child.

Event Delegation: Parent element handles events for its child elements.
