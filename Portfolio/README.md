# Pallavi S Bhat — Personal Portfolio

A clean, responsive, and performant personal portfolio built with React 19, Tailwind CSS, and Vite.

## 🚀 Live Demo
Visit the live portfolio at: [https://pallavi-portfolio.vercel.app](https://weather-forecast-pallavii.vercel.app/) *(or your deployed Vercel URL)*

## 🛠 Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** GSAP (ScrollTrigger)
- **Linter:** Oxlint

## 📂 Project Structure
```text
Portfolio/
├── public/              # Static assets (favicons, profile picture)
├── src/
│   ├── components/      # Modular UI components
│   │   ├── Navbar.jsx       # Responsive sticky header with scroll indicator & mobile menu
│   │   ├── Hero.jsx         # Personal intro, credentials, and quick links
│   │   ├── Projects.jsx     # Filterable project showcase with live/repo links
│   │   ├── Skills.jsx       # Categorized technical competencies
│   │   ├── Experience.jsx   # Timeline of internship and education
│   │   ├── Contact.jsx      # Functional contact form and social channels
│   │   ├── Icons.jsx        # Clean SVG brand icons (GitHub, LinkedIn)
│   │   ├── Footer.jsx       # Footer with copyright and quick socials
│   │   └── BackToTop.jsx    # Smooth scroll-to-top button
│   ├── App.jsx          # Root page layout
│   ├── index.css        # Global Tailwind and font styles
│   └── main.jsx         # Application entry point
├── index.html           # Document root & typography definitions
└── vite.config.js       # Vite configuration
```

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Pallavi-SBhat/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
